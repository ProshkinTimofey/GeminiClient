# Gemini Native Client для iOS 15.8 (iPhone SE 1-го поколения)

Полностью нативный легковесный клиент для **Google Gemini**, созданный по архитектурным принципам **Onegram** (максимальная производительность, 0% CPU в простое, ~30 МБ RAM, отсутствие постоянного тяжелого WebKit в фоне и работа без сторонних API-ключей).

Специально оптимизирован под компактный 4-дюймовый дисплей **iPhone SE 1-го поколения** (320x568 pt, чип Apple A9, iOS 15.8).

## Вдохновение и благодарности (Credits)

Этот проект вдохновлен выдающейся работой **[IllyaGIF](https://github.com/IllyaGIF)** и его проектом **[Onegram](https://github.com/IllyaGIF/Onegram)** — неофициальным нативным клиентом Telegram для устаревших версий iOS (iOS 4.3 – 10.x).

Onegram на практике доказал сообществу, что старым устройствам Apple не нужны тяжелые, медленные и высаживающие аккумулятор браузерные веб-обертки. Единственно верный путь к идеальной плавности и автономности — это чистый нативный интерфейс (UIKit) и работа напрямую с протоколами серверов через легковесные системные сетевые запросы. Именно эта философия была взята за основу при разработке данного клиента Google Gemini.

## В чем отличие от старых веб-оберток?

| Параметр | Старая веб-обертка (WKWebView) | Настоящий нативный клиент (Новый GeminiClient) |
| :--- | :--- | :--- |
| **Движок интерфейса** | WebKit (15+ МБ тяжелого JS от Google) | **100% чистый UIKit** (нативные таблицы, CoreText) |
| **Расход памяти (RAM)** | 250 – 350 МБ (на грани вылета на 2 ГБ RAM) | **~30 – 35 МБ** (уровень системных «Заметок») |
| **Расход батареи** | Высокий нагрев, фоновый JS, утечки | **Минимальный** (0% CPU в простое, нет фоновых скриптов) |
| **Роль WebKit** | Работает постоянно, рендерит весь сайт | **Одноразово**: только для входа в Google, после чего **полностью уничтожается из памяти** |
| **Работа с данными** | Отображение веб-страницы Google | **Нативный сетевой RPC-движок (`URLSession`)** через протокол `batchexecute` |
| **API ключи** | Не требуются | **Не требуются** (используется твоя реальная сессия Google) |

## Архитектура проекта

```
┌────────────────────────────────────────────────────────┐
│  1. АВТОРИЗАЦИЯ GOOGLE (Одноразово)                    │
│  Всплывающее окно входа Google -> Забираем сессионные  │
│  куки (__Secure-1PSID, __Secure-1PSIDTS) ->            │
│  ПОЛНОСТЬЮ УНИЧТОЖАЕМ WebKit из памяти!                 │
└──────────────────────────┬─────────────────────────────┘
                           │ Куки надежно сохранены в Keychain
                           ▼
┌────────────────────────────────────────────────────────┐
│  2. СЕТЕВОЙ RPC-ДВИЖОК (URLSession, actor)             │
│  Напрямую вызывает внутренний Google RPC:              │
│  - gemini.google.com/_/BardChatUi/data/batchexecute    │
│  • Рукопожатие и токен SNlM0e (warmupSession)          │
│  • Получение списка реальных чатов (MaZiqc)            │
│  • Загрузка истории выбранного чата (hNvQHb)           │
│  • Отправка сообщений и стриминг ответа (fReq)         │
└──────────────────────────┬─────────────────────────────┘
                           │ Нативные структуры данных
                           ▼
┌────────────────────────────────────────────────────────┐
│  3. НАСТОЯЩИЙ НАЦИВНЫЙ UI (Чистый UIKit, 60 FPS)       │
│  • SlideOverDrawerController: боковая шторка с жестом  │
│  • HistorySidebarViewController: список чатов аккаунта │
│  • ChatViewController: нативная таблица сообщений      │
│  • NativeMarkdownRenderer: фоновый парсер с NSCache   │
│  • GrowingInputBarView: саморастущее поле 1-5 строк    │
└────────────────────────────────────────────────────────┘
```

## Структура файлов проекта

| Файл | Назначение |
| :--- | :--- |
| **`Gemini/AppDelegate.swift`** | Главная точка входа приложения `@main`, монтирующая `AppCoordinator`. |
| **`Gemini/AppCoordinator.swift`** | Координатор жизненного цикла, проверка Keychain, запуск чата и авто-перелогин. |
| **`Gemini/GeminiAuthSession.swift`** | Одноразовый вход в аккаунт Google, перехват кук и детерминированное уничтожение WebKit (`destroyWebView()`). |
| **`Gemini/GeminiRPCClient.swift`** | Потокобезопасный `actor` на `URLSession`, парсер `)]}'`, запросы к `batchexecute` и `StreamGenerate`. |
| **`Gemini/NativeMarkdownRenderer.swift`** | Высокопроизводительный фоновый парсер Markdown (код, жирный, списки) с кэшем `NSCache`. |
| **`Gemini/GrowingInputBarView.swift`** | Многострочное поле ввода, плавно растущее от 1 до 5 строк с трекингом клавиатуры. |
| **`Gemini/ChatCells.swift`** | Нативные ячейки сообщений (баббл пользователя справа, полноразмерный ответ модели с кнопкой копирования). |
| **`Gemini/HistorySidebarViewController.swift`** | Левая боковая панель со списком твоих реальных веток из Google, кнопкой «Новый чат» и «Выйти». |
| **`Gemini/SlideOverDrawerController.swift`** | Контейнер с выдвижной шторкой по свайпу от левого края (ширина 260 pt / 80%). |
| **`Gemini/ChatViewController.swift`** | Экран чата с автоскроллом, нативной клавиатурой и индикатором «Gemini думает...». |
| **`Gemini/Info.plist`** | Конфигурация iOS 15, системные разрешения и темная тема. |
| **`.github/workflows/build.yml`** | Сценарий автоматической компиляции в `.ipa` на облачном Mac через GitHub Actions. |

## Сборка и установка через GitHub Actions

1. Создай приватный репозиторий на **GitHub** (например, `GeminiClient`).
2. Запушь содержимое этой папки в репозиторий:
   ```bash
   git init
   git branch -M main
   git add .
   git commit -m "Initial Onegram-style Gemini Client"
   git remote add origin https://github.com/ВАШ_ЛОГИН/GeminiClient.git
   git push -u origin main
   ```
3. Во вкладке **Actions** запустится задача сборки на macOS раннере с Xcode.
4. Через 2 минуты в блоке **Artifacts** скачай `Gemini_Native_iOS15.ipa`.
5. Установи IPA на iPhone SE через **TrollStore** (благодаря **AppSync Unified** и TrollStore сертификаты не требуются).
